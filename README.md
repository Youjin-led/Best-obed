# The Best Obed — главная страница

Боевая версия главной от 24 сентября 2026. Один самодостаточный файл `index.html`: вёрстка, стили и скрипты внутри, сборка не нужна. Рядом лежит отдельная страница меню `menu.html` и исходные данные меню `menu.md`.

## Как открыть

Двойной клик по `index.html`. Работает в любом современном браузере, интернет нужен только для шрифтов Google Fonts.

## Что внутри

- **Верхняя полоса** — доставка по Москве и Московской области, статусы (УПД, ХАССП), телефон. Переключатель городов удалён.
- **Шапка** — липкая, с размытием при скролле; навигация ведёт на якоря и страницу «Меню» (`menu.html`).
- **Герой** — крупный редакционный заголовок «точно ко времени», иллюстрация ланчбокса с бейджами (новое меню каждый день, ХАССП, от 290 ₽, для команд от 10 человек).
- **Линия раздачи** — бегущая лента с фото блюд на белом фоне (слоты `photos/<slug>.jpg`), с паузой по наведению.
- **Как работаем** — четыре шага сотрудничества, пробный обед на 5 человек.
- **Кому подходит** — четыре карточки аудитории вместо кейсов.
- **Пример меню недели** — пять колонок (пн–пт): суп, горячее, гарнир, салат; ссылка «Всё меню, 117 позиций» → `menu.html`.
- **Отзывы клиентов** — карточки с текстом и оценками.
- **Тёмная лента качества** — своя кухня и ХАССП, собственная доставка в термоконтейнерах, прозрачная отчётность, меню без повторов (более 400 блюд).
- **Квиз-расчёт** — четыре шага до бюджета, количество человек вводится свободно, смета до отправки контактов.
- **День кухни** — таймлайн 04:40 → 12:30.
- **FAQ** — аккордеон с плавным раскрытием.
- **Финальный блок** — жёлтая заявка на пробный обед (5 комплексов, бесплатно от 10 человек).
- **Подвал и плавающая панель** — на мобильных превращается в нижний бар.

## Сопутствующие файлы

- `menu.html` — отдельная страница «Меню и цены»: меню недели, полный каталог 117 позиций, форма заявки на пробный обед.
- `menu.md` — исходные данные меню (плановая таблица на неделю, каталог по категориям) — и для главной, и для `menu.html`.
- `photos/` — не в репозитории: 8 фото блюд для линии раздачи, имена файлов `borshch.jpg`, `curry.jpg`, `pasta.jpg`, `cod.jpg`, `salad.jpg`, `plov.jpg`, `crepes.jpg`, `chickpea.jpg` (белый фон). Пока фото нет, лента показывает подпись-слот.

## Технические возможности

- Один город (Москва и МО): телефон, адрес кухни и цены статичны, в JS объект `C` содержит только `msk`.
- Три темы: светлая, тёмная, авто — переключатель в шапке.
- Появление блоков при скролле (IntersectionObserver), отключается при `prefers-reduced-motion`.
- Формы показывают состояние успеха без отправки данных.
- `color-mix` и `backdrop-filter` для стеклянных элементов — требуется современный браузер.

## Дизайн-система

- Заголовки и цифры: Bitter 600 / 700, табличные знаки
- Текст: Inter 400–700
- Палитра: тёплый крем `#FAF6F0` фон, чёрный `#17130E`, жёлтый `#FFC400`, терракота `#B0442A`, олива `#6E8F4B`
- Скругления: карточки 18 px, кнопки 12 px, теней аккуратно
- Обе гарнитуры бесплатны, под OFL, коммерческое использование разрешено

## Что заменить перед запуском

1. Иллюстрации нарисованы кодом (SVG). Слоты подписаны: «фотосъёмка блюд» для ленты, сцены площадок в карточках. Нужна съёмка: 8 блюд сверху, 4 кадра площадок, 3 кадра производства.
2. Телефоны, адреса кухни, ИНН — заглушки вида `+7 495 000-00-00`.
3. Цены и метрики условные — согласовать с клиентами.
4. Формы не отправляют данные. Подключить amoCRM или почту, повесить цели Яндекс.Метрики и GA4.
5. В `<head>` лежит разметка Schema.org: Organization, FoodEstablishment (Москва и МО), FAQPage. После правки контактов обновить и её.

## Направления развития (референсы из живых сайтов: baza.menu, stolicaest.ru, lunchmarketcorp.ru, yamdiet)

1. **Личный кабинет / бот заказов** — сотрудники выбирают меню сами, секретарь перестаёт собирать заказы вручную.
2. **Конструктор обеда** — сборка из 30+ позиций: суп, горячее, гарнир, десерт, напиток, с учётом аллергенов.
3. **Личный кабинет для клиента** — реестр заказов, лимиты на сотрудника, фильтры по датам и подразделениям.
4. **Перенос на Next.js 15** — остальные посадочные: услуги, районные ветки.
